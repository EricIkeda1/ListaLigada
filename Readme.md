# Lista Ligada em Java

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de implementar uma lista ligada simples em Java, como parte de uma atividade prática da faculdade.

A ideia principal foi trabalhar com uma estrutura de dados onde os elementos não ficam armazenados de forma contínua na memória, mas sim conectados através de nós. Cada nó guarda um valor inteiro e uma referência para o próximo elemento da lista.

---

## Como funciona

A lista começa vazia e, conforme novos valores são inseridos, eles são adicionados sempre no início da estrutura.

Por exemplo, ao inserir os valores 5, 10 e 15 nessa ordem, o resultado final da lista será:

15 -> 10 -> 5

Isso acontece porque cada novo elemento passa a ser o primeiro da lista.

---

## O que foi implementado

Durante o desenvolvimento, foram criadas três classes:

- Uma classe chamada **No**, responsável por representar cada elemento da lista.
- Uma classe chamada **ListaLigada**, que controla a estrutura da lista e possui os métodos principais.
- Uma classe **Aplicacao**, que contém o método principal (main) e serve para executar o programa.

---

## Funcionalidades

A aplicação possui duas funcionalidades principais:

- Inserir números inteiros no início da lista.
- Percorrer a lista exibindo todos os valores armazenados.

---

## Execução

Ao executar o programa, alguns valores são inseridos na lista e, em seguida, são exibidos no console.

A saída mostra os elementos na ordem em que estão encadeados.

---

## Objetivo da atividade

O projeto atende aos requisitos propostos na atividade, que eram:

- Implementar uma lista ligada de inteiros.
- Criar um método para inserir elementos no início da lista.
- Criar um método para percorrer e imprimir os elementos.
